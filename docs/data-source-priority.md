# 数据源优先级总表

> 这份文档是**唯一权威**。代码里的降级链、注释、以及各工具的输出，都以这张表为准。
> 更新日期：2026-11-23。所有「实测」结论都来自本机直连测试，不是转述。

## 0. 排序原则

借用 `simonlin1212/a-stock-data` 的封 IP 风险表，并**逐条实测验证**：

> **能用腾讯 / 交易所官方，就别用东财。**

因为东财有风控，连续几个请求后就开始返回空——这不是偶发故障，是设计上的必然。我今天实测时就撞到过三次。

| 风险等级 | 含义 |
|---|---|
| 不封 IP | 可以放心用，只需防单入口限流 |
| 极低 | 避免高频即可 |
| 低 | 正常频率没问题 |
| **中（会封）** | 必须串行 + 限流，且只用于「别人拿不到、只有它有」的数据 |

## 2. 明确不可用

| 数据 | 结论 | 原因 |
|---|---|---|
| **北向资金逐日净额** | ❌ 不可用 | 接口返回 `dayNetAmtIn` **全 0** —— 额度披露已停，不是接口坏 |
| **涨跌家数（全市场）** | ❌ 未验证通过 | 东财 `clist` 的 `fs` 组合多次尝试返回空 |
| **连板梯队细分** | ❌ 不提供 | 只有每只股的连板数（`lbc`），没有「3板几只」这种分组 |
| 财经新闻 | ❌ 未接入 | 需要具体的新闻 API，`search_web` 检索质量不可靠 |

**这些一律写进工具输出的 `unavailable` 数组**，不假装有。

## 3. 代码里的落点

| 文件 | 管什么 |
|---|---|
| `lib/stock/stock_source.dart` | K 线三级降级（腾讯→新浪→东财）、快照三级降级（同序）、同源重试一次 |
| `lib/stock/market_source.dart` | 指数（腾讯）、板块/涨停/两融/龙虎榜/热榜（东财 + `_Em.serial` 限流） |
| `lib/tools/stock_tools.dart` | 工具层：每个输出都带 `data` 块（source/adjust/as_of/quality） |

## 4. 限流规则

| 源 | 规则 | 位置 |
|---|---|---|
| 腾讯 K 线 | 单入口约 600 次后限流，靠多域名轮换 | `stock_source.dart` |
| 腾讯快照 | 无特殊限制 | — |
| 新浪 | 需要 `Referer`，否则 403 | 各 fetcher 里显式传 |
| **东财（全部）** | **串行 + 至少 350ms 间隔** | `_Em.serial` |
| 同源重试 | 每次降级前先重试 1 次（250ms 退避），确定性错误不重试 | `_retryOnce` / `_retryOnceQuote` |

## 5. 降级必须留痕

降级到备源**不能静默**，否则模型会把不复权数据当复权、把延迟价当实时价：

| 载体 | 字段 |
|---|---|
| K 线 | `KlineSeries.fallbackReason` → 工具输出 `data.degraded_reason` |
| 快照 | `Quote.fallbackReason` + `Quote.delayed` → 工具输出 `degraded_reason` + `note` |
| 市场 | 每个模块独立的 `errors` 字典 |
