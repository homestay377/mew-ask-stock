# mew 问股 v1.10.4

这一版加上子智能体：主智能体可以把活分出去，几个任务并行跑。

## 子智能体是什么

主智能体多了一个工具 `dispatch_subagents`。你可以在一次调用里塞进多条任务，它们会**同时开工**，跑完把结论交回来；依赖别人产出的（复核、出方案）把 `wait_for_others` 设成 true，会等前面完成再动手。

内置 5 个，都能改：

| 名字 | 干什么 | 只读 |
|---|---|---|
| 行情侦察 | 报价、多级别结构、自选扫描，先摸清现状 | 是 |
| 结构审查 | 复核缠论结构、背驰力度、买卖点是否成立 | 是 |
| 资料研究 | 基本面与公开资料，结论要带出处 | 是 |
| 策略方案 | 给支撑压力、加减仓条件、失效位 | 是 |
| 图文标注 | 把已定的价位画到图上 | 否 |

设置 → 扩展 → 子智能体：可增删、启停、改提示词、选独立模型、勾工具白名单。不勾白名单＝可用主智能体当轮的全部工具。

## 怎么接进去的

MewHub 的工具契约是 `execute(args)`，只给参数，拿不到模型和会话。所以没有给每个工具加参数，而是由 `ChatController._runTools` 用 `runZoned` 注入一份 `ToolRunContext`：分派工具从 Zone 里取，其余工具一行不用改。分派工具自己的等待上限放宽到 10 分钟，别的工具仍是 3 分钟。

## 边界（都写进 docs/subagents.md）

- 子智能体**永远拿不到分派工具本身**，最多一层，不会套娃。
- 只读＝白名单再减掉 `chart_annotate` / `stock_panel_show`；过滤在引擎里做，设置页勾错也不会漏出去。
- 一次分派最多 6 条任务，单任务最多 24 步，单个工具 3 分钟。
- 子智能体的 token **还没**归集进「用量统计」。
- 过程暂时是黑盒：跑完一次性返回，看不到中间在做什么（下面 P2 接着做）。
