## 2. 预置 8 条股票分析短句

第一次启动自动装上（和缠论世界书共用 `.stock_knowledge_seeded` 标记，**只装一次**，删掉不会再回来）：

| 标题 | 内容要点 |
|---|---|
| 日线结构 | `analyze_chan`：笔 / 中枢区间 / 背驰 / 买卖点，按三段式写 |
| 多周期共振 | `stock_levels`：日/周/60分/30分方向，指出哪两级相反 |
| 位置判断 | 支撑压力怎么算的、加仓条件、减仓条件、失效位 |
| 量价配合 | 放量突破还是缩量反抽，落到具体几根 K 线 |
| 团队分析 | 用智能体团队分派，最后自己整合 |
| 自选扫描 | `scan_stocks` 按结构健康度排序，给前 5 |
| 基本面快查 | `get_fundamental`，取不到的明确写「取不到」 |
| 数据核验 | 查数据新鲜度、盘中价当收盘价、跨周期矛盾 |

每条都写清「要什么输出」，避免模型只回一句「偏强」。

## 4. 新增市场数据源 `market_overview`

### 只做实测确认可用的

我在本机直连实测了四个接口：

| 接口 | 实测结果 | 是否采用 |
|---|---|---|
| 指数 `push2.eastmoney.com/api/qt/ulist.np/get` | ✅ 返回上证 3538.95 / 深成 10454.37 / 创业板 2280.2 | 采用 |
| 板块涨幅榜 + 主力净流入 `clist/get` `fs=m:90+t:2` | ✅ 返回视频媒体 +15.21% / 机器人 +9.54% 等 496 个板块 | 采用 |
| 涨停池 `push2ex.eastmoney.com/getTopicZTPool` | ⚠️ 有响应但当日返回空池，未验证可靠 | 不采用 |
| 涨跌家数 | ❌ `fs` 参数组合多次尝试均返回空 | 不提供 |

### 工具输出

```json
{
  "indices": [{"code":"000001","name":"上证指数","price":3538.95,"change_pct":0.15,"as_of":"2026-11-23 11:06（实时取数，盘中会变）"}],
  "sectors_title": "涨幅榜",
  "sectors": [{"code":"BK1408","name":"机器人","change_pct":9.54,"net_inflow_yi":9.22,"leader":"…","leader_pct":…}],
  "sector_total": 496,
  "unavailable": ["涨停家数", "连板梯队", "赚钱效应", "新闻资讯"],
  "source": "东方财富 push2（免费接口，无 SLA，可能限流）"

```

### 明确禁止的事

`promptHint` 里写死了：

- 指数与板块数字必须来自工具，不许凭印象说「今天普涨」；
- **不许用板块涨幅反推涨停家数**——那正是之前那种「60 只代表股反推板块判断」的补丁式做法；
- 取不到就写取不到（`error` 字段会说明是否被限流）。

### 限流说明

这几个接口是免费非官方接口，我今天实测时就撞到过一次限流（连续请求后返回空）。限流时工具返回 `sectors_error`，让模型如实说取不到，而不是编数字。
