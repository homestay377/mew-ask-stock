# mew 问股 v1.10.1

修两处图表问题。

## 分时图补上均价线

- 口径按 A 股习惯：**累计成交额 / 累计成交量**（volume 是「手」，所以乘 100 换成股），不是价格的简单平均。
- 黄线 + 左上角「均价 x.xx」标注，盘中和现价容易看混的地方一眼能分清。
- 该分钟没成交时线断开，不画成 0。
- **指数不画这条线**：指数分时的 amount 是成分股成交额，跟点位没关系（实测算出来是 14，点位是 3533）。ETF / 个股照常画。
- 量纲兜底：首点均价偏离首点价格超过 10%，说明这家源的量纲不是「手 + 元」，直接不画，不硬算。

## K 线面板可以拖拽调高度

- 展开后顶部加了把手（中间一道短横），上下拖就能调高矮，范围 160 ~ 屏幕高度的 78%。
- 高度会记住（存在 `stock_panel.json`），下次打开还是你上次调的那个大小；文件坏了自动回默认。

## 关于子 agent

这一版**没有**子 agent。当前 MewHub 的工具是不带会话上下文的纯函数（`AppTool.execute(args)`），工具里拿不到模型和会话，所以没法「在工具里再开一次对话」。要做需要改工具接口 + 加嵌套执行器和预算控制，属于独立一期的事，不在这次里凑。
