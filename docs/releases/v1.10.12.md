# mew 问股 v1.10.12

## 修「面板显示 3 个运行中、共享任务却是 0」

你截的那张图里，`3 个运行中` 和 `共享任务 0` 是同一帧里自相矛盾的两个数——一个数任务行里的 running，另一个数任务行的总数。能出现这种组合，只有一个解释：**界面拿到的任务板是空的，而 running 计数来自另一份数据**。

查下来是两个原因叠在一起。

### 原因一：界面只认序列化快照

面板和卡片都只读 `ToolPart.meta['board']` —— 那是 `board.toJson()` 的字符串快照，靠 `pushBoard` 一步步写进去。那一步只要没写进去（或写入的时机不对），界面就永远是空的，而且**不会有任何报错**。

改法：`sub_agent_tools` 导出 `activeTeamBoard`（内存里那张活的任务板），界面优先读它，meta 只做兜底。

```dart
final live = activeTeamBoard;
if (live != null && live.tasks.isNotEmpty) return live.toJson();
```

### 原因二：卡片等父级重建

`ToolCard` 是 `StatefulWidget`，之前完全依赖聊天页 rebuild 才更新。面板打开着、或聊天页进入某些状态时，父级不重建，卡片就「一点反应都没有」。

改法：卡片自己在有未返回的分派时开一个 400ms `Timer`，返回后自动停。

```dart
bool get _liveTeam =>
    widget.part.output == null &&
    (widget.part.name == 'dispatch_subagents' || widget.part.name == 'add_team_tasks');
```
