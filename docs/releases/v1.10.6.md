# mew 问股 v1.10.6

这一版只做一件事：把身份理顺。以前 App 里外还漏着几个「MewHub」——那是底座供应商的名字，不是这个项目。

## 改了什么

- 关于页的大标题、开源许可页的应用名：`MewHub` → **mew问股**
- 引导页标题同上
- 新会话没有标题时，默认标题从 `MewHub` 改成 **mew问股**（通知里显示的就是这个）
- 更新检查的 `User-Agent` 改成 `mew-ask-stock`
- **下载文件名终于对上了**：`MewHub-1.10.5-android-arm64-v8a.apk` → **`mew-wengu-1.10.6-android-arm64-v8a.apk`**
- Release 标题从「MewHub v1.10.6」改成「mew问股 v1.10.6」

桌面图标下面的名字本来就是「mew问股」（`android:label`），没变。

## 故意没改的

- `pubspec.yaml` 的 `name: mewhub`。这是 Dart 包名，`package:mewhub/...` 出现在两百多个 import 里；改它对用户零可见收益，但会制造一次全仓改动。真要改得单独做，并同步改 CI。
- 备份（`backup.dart`）和配置迁移（`config_transfer.dart`）里的 `'app': 'MewHub'` 标记。这是文件格式的判据，改了以前的备份就导不回来了。它只在文件内部，界面看不到。
- README 和关于页里「基于 MewHub」的说明——这是事实，上游就是它。

## 验证

CI 全绿（analyze + test + Android + iOS）。因为只是文案和打包命名，没有新增测试；`dart format` 187 文件 0 changed。
