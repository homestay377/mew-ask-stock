# mew 问股 v1.10.0

按《产品提升建议书》把四个阶段一次性落地：先把分析修准，再让 AI 真正看懂图，然后做多周期研判，最后把行情数据的可靠性补齐。

## 一、分析可靠性（阶段 1）

- **周期不再错位**：`analyze_chan` / `stock_kline` / `stock_levels` 统一按「用户显式指定 > 面板当前周期 > 默认」取周期。面板停在分时不支持缠论就明确报错，不再静默切到日线。
- **去掉未来数据**：背驰的级别判定改用「信号时点之前已经形成的中枢」，截断回放实测修掉了 idx=123 把「笔背驰」误判成「趋势背驰」的问题。买卖点选中枢改用 `s <= idx` + 1.5 倍中枢高度约束。
- **未来函数说清楚**：`BACKSET` 等保留绘图语义，但中枢右边界会重绘这件事写进了文档；4 个未实现函数（NAMELIKE / CODELIKE / ZTPRICE / DTPRICE）不再静默，会明确上报——它们只影响涨停跌停价的 NODRAW 输出，不改变笔和中枢。

## 二、图表与 AI 联动（阶段 2）

- 新增 `chart_context` 工具：标的一、周期、数据源、可视范围、十字光标那一根的 OHLCV、当前主副指标值、缠论计数与中枢位置，以及**复权口径、最后一根收没收、数据是缓存还是刚拉的、质量问题**。
- 长按某根 K 线 →「问这根」带上该根真实数值；长按结构 →「问结构」带上中枢区间 ZG/ZD、背驰力度或买卖点依据，并追问「结构重绘后这个判断还算不算数」。

## 三、多周期研判（阶段 3）

- `trendOf()` 用最近 4 笔的高低递进判 上升 / 下降 / 震荡，`stock_levels` 每级返回 `trend`、`source`、`adj`、`bars_adequate`、`last_date`、`formula_gaps`。
- 新增 `conflicts`：只在 周 vs 日、日 vs 60 分、日 vs 30 分 方向相反时报，不做加权计数。
- 结论模板固定五步：大级别趋势 → 日线位置 → 60 分是否一致（以哪级为准）→ 关键价位 → 支持或推翻的条件。

## 四、行情数据可靠性（阶段 4）

- 新增 `lib/stock/data_quality.dart`：时间解析（腾讯分钟是 12 位且为**结束时刻**）、质量体检（日期重复 / 倒序 / 跳空 / OHLC 不自洽 / 负成交量）、收盘判定。
- `KlineSeries` 补 `source` / `adjust` / `fallbackReason` / `fetchedAt` / `fromCache` / `cacheAge` / `quality` / `clock` / `provenance`；三级降级即使成功也记下主源错误。
- 缓存年龄按**原始拉取时间**算，刷新失败不再静默；面板提示条按严重度只显示一条（数据异常 > 已切备源 > 缓存陈旧 / 刷新失败）。

## 验证（真跑过）

- golden：640 根 → 38 笔 / 4 中枢 / 6 背驰 / 3 买卖点，中枢 `183.86-158.95`、`140.80-123.49` 与通达信截图一致。
- 新增回归：等比缩放 0.5 / 2 / 100 倍结构完全不变；除权跳空 0.85 不崩；空 / 单根 / 全等价价格不造结构；截断回放的信号级别一致。
- CI：`flutter analyze --fatal-infos` 通过，`flutter test` 全绿。

## 已知限制

- 没有交易日历，节假日不区分；收盘判定按 15:00 与分钟线结束时刻算。
- 中枢右边界（`e`）会随后续 K 线重绘；ZG/ZD 稳定。
- 三买 / 三卖未验证「回抽过程」，是规则简化。
- 4 个未实现函数只影响涨跌停价输出，不影响笔 / 中枢 / 背驰 / 买卖点。
- 大盘、板块、资讯（建议书第七节）未做——需要先确认可靠且可合法使用的数据源。
