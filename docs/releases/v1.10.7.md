# mew 问股 v1.10.7

子智能体 P3：能互相问了，团队也能看见了。

## 新增：互相提问

子智能体多了一个 `ask_peer` 工具：可以把问题转给同批的另一个同伴，拿到它的判断再继续。比如「行情侦察」不确定某个买卖点，就去问「结构审查」。

限制是硬的：不能问自己、每个任务最多问 3 次、深度只到「主控 0 → 子智能体 1 → 被问的同伴 2」，再往下不传。所以不会出现两个智能体互相问个没完。

## 新增：智能体团队面板

聊天页抬头加了一个人形图标，点开就能看到：

- **成员**：主控 + 每个子智能体一张卡，带「只读」/「已停用」标签；跑起来的时候状态会变成它在干什么（例如「行情侦察 · stock_kline(300274)」），跑完回到「待命」。
- **共享任务**：本会话里每一次分派/讨论，点开看每个子智能体的产出、步数、耗时、token。
- 面板里的数据全部来自本机文件与当前会话，不发任何请求。

## 新增内置：数据核验

只读的第六个子智能体，专门挑四类毛病：

1. 数据是不是跨了交易日还没更新（看 `fetched_at` / `closed` / `from_cache` / `quality`）；
2. 有没有拿上一根 K 线的价位当现状；
3. 不同周期、不同工具的结论是否互相矛盾；
4. 有没有把「取不到」写成数字。

## 为什么没有「大盘/板块/资讯」模块

你给的那套设想里有市场模块（指数环境、板块强弱、赚钱效应）和资讯模块。这两个我**没有做**，原因不是懒：现在只有个股 K 线与基本面接口，没有板块强弱、涨停家数、新闻源。硬加就等于让模型编数字，而这正是我们一直避免的事。

要加得先有数据源：指数与板块可以用腾讯/东财的行情接口再取一批；资讯要么接搜索服务（`search_web`），要么接具体新闻 API。等你决定接哪个，我再把它们做成子智能体。
