# mew 问股 v1.10.16

## 1. 行情源：同源先重试一次再降级

原来是 `kline()` 里三级降级链，**一次失败就直接跳到下一个源**：

```dart
for (final fetcher in [tencent, sina, eastmoney]) {
  try { return await fetcher(); } catch (e) { errors.add('$e'); }
}
```

网络抖一下，腾讯（前复权）就掉到新浪（**不复权**），整份分析的复权口径跟着变——模型拿到 `adjust` 字段也不敢用，结论就虚了。

现在每源内部先重试一次（250ms 退避）再降级：

```dart
Future<KlineSeries> _retryOnce(Future<KlineSeries> Function() fetcher) async {
  for (var i = 0; i <= sourceRetries; i++) {
    try { return await fetcher(); }
    catch (e) {
      if (msg.contains('不支持') || msg.contains('非法') || msg.contains('无法识别')) break;
      if (i < sourceRetries) await Future.delayed(const Duration(milliseconds: 250));
    }
  }
  throw last;
}
```

确定性错误（周期不支持、代码非法）不重试，避免白白等 250ms。

## 2. 子智能体产出铺在卡片上

原来已完成的任务只在详情弹窗里能看产出，卡片上只有状态。

现在：

- **聊天流的分派卡片**：每条已完成的子任务直接显示结论摘要（最多 3 行），不用点开；
- **团队面板的任务卡**：同样显示 3 行摘要。

配合上一版的「运行中显示实时文本」，现在整条生命周期都看得见：

```
◐ 从研报与公告里找 2026 年收入指引…        [运行中]  ⏹
  t2 · 研究员 · 2m14s
  · 思考 先看年报口径，再比三家券商…
  · http_request ✓ 820ms

✓ 三季报营收同比 +18.6%，毛利率 31.2%…     [已完成]
  t1 · 研究员 · 3m02s
```
