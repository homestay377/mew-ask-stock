# mew 问股 v1.10.10

## 子智能体：能看到它在写什么了

上一版把任务板搬进了聊天流，但只能看到「运行中 / 等待前置」这种状态词——看不到子智能体到底在干什么。这一版补上逐段内容和每步工具。

### 1. 逐段实时输出

`SubAgentRunner` 新增 `onLive` 回调，流式期间按 **120ms** 节流推送（和清水的 `LIVE_PUBLISH_INTERVAL_MS` 同频）：

```dart
await for (final chunk in ai.stream(msgs, params, cancel: _cancel)) {
  round.add(chunk);
  final live = _textOf(round.parts);
  if (live.isNotEmpty) lastText = live;
  publish('running');
}
```

每跑完一个工具强制推一次，结束时推 `done` / `failed`。

卡片上现在能直接看到：

```
◐ 从研报与公告里找 2026 年收入与利润的指引…   [运行中]  ⏹
  t2 · 研究员
  · http_request ✓ 820ms
  · stock_levels ✓ 340ms
```

### 2. 任务板带实时态

`TeamTask` 新增 `liveStatus` / `liveOutput` / `liveSteps` / `liveIn` / `liveOut` / `liveMs`。
`toJson` 有 `result` 用 `result`，没有就用实时态——所以任务还没结束就有内容可画。
任务板的 `tokens_in` / `tokens_out` / `elapsed_ms` 把还在跑的任务也算进去。

### 3. 对话级 token 合计

团队面板顶部：

```
3 个运行中  1 个等待前置
本次合计 ↑157.9K ↓537 · 158.4K tokens · 23m10s
```

口径是「这段对话里所有分派累加」，不是单个任务——对应清水的 `subAgentUsageTotals()`。

### 4. 修掉一个真正让界面冻住的 bug

`pushProgress` 原来是：

```dart
if (progress.length >= 12) return;   // ← 满 12 行直接返回
```

**跑到第 12 行之后，界面再也不刷新**。一个跑十几分钟的分派，看起来就是卡在那一刻不动。这就是「假界面」的另一半原因。

改成滚动窗口：保留最后 12 行，但每次都推。

### 5. 顺手修的

工具轮通常没有正文，原来的 `lastText = _textOf(round.parts)` 会把流式期间已经显示的文本清空，现在只有非空才覆盖。
