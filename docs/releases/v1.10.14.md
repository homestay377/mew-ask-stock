# mew 问股 v1.10.14

## 团队自报「没做到」的五条，四条已补，一条只能标注

截图里那段「团队这次没做到的事」写得挺诚实，但它列的其实是**我们工具的缺口**，不是市场的不确定性。逐条处理如下。

### ① 中枢只有索引、没有日期 → 已补

`boxes` 原来只有：

```json
{"tag": "...", "start": 27, "end": 386, "zg": 183.86, "zd": 158.95}
```

现在：

```json
{
  "tag": "...", "start": 27, "end": 386,
  "start_date": "2025-06-11", "end_date": "2025-12-02",
  "zg": 183.86, "zd": 158.95
}
```

`signals` / `points` 同样带上 `date`，输出顶层再加 `bars_used`。模型不用再自己换算，也就不会再报「±1 交易日误差」。

### ② MACD 面积无法复算 → 已补

`ChanSignal` 增加 `fromIdx` / `areaPrev` / `areaCur`，输出：

```json
{"label": "底背驰(笔)", "strength": "0.96",
 "from_idx": 512, "macd_area_prev": 1.83, "macd_area_cur": 1.76}
```

面积比模型自己就能算，不必再说「面积是公式内部算的，无法复算」。

### ③ 4 个公式函数未实现 → 已实现

`CODELIKE` / `NAMELIKE` / `ZTPRICE` / `DTPRICE`：

| 函数 | 实现 |
|---|---|
| `CODELIKE('33')` | 代码去掉市场前缀后按前缀匹配 |
| `NAMELIKE('ST')` | 名称包含匹配（大写） |
| `ZTPRICE(base, n)` | `base × (1 + n)`，四舍五入到分 |
| `DTPRICE(base, n)` | `base × (1 - n)`，四舍五入到分 |

为此 `runFormula` / `Chanlun.analyze` 新增 `symbol`、`name` 入参，`stock_analyzer` 从 `KlineSeries` 带进去。

这 4 个在公式里都是 `NODRAW`，只算涨停跌停价与板块判定，**不影响笔和中枢**；但缺了会产生 `formulaErrors`，模型看到就会对整份结构打折扣。

### ④ 中枢数量口径不一致 → 输出可自证 + 提示禁止跨工具比较

`chart_context` 报 4 个、`stock_levels` 报 3 个，根因是**两边喂的 K 线根数不同**（窗口短了会在最左沿多造一个中枢）。两个工具现在都带根数，`analyze_chan` 加 `bars_used`。

`promptHint` 明令：不要跨工具比较中枢「个数」，要看就用 `bars_used` 自己核对。

### ⑤ `repaints=true` → 消不掉，但已显式声明

`BACKSET` 的固有行为：中枢右端会随新 K 线上移。这个**没法消除**，除非放弃 `BACKSET`，那就和通达信口径不一致了。

现在输出里明写 `repaints: true` 与 `repaints_note`，并要求结论里写明「图上结构不等于当时可确认的结构」。

### ⑥ 盘中价漂移 → 标注 + 禁令

`last.is_intraday = clock.closed == false`。

`analyze_chan` 的 `promptHint` 现在明令：盘中价不能当收盘价、不能当「现状」写进结论；要写就写「盘中价，收盘后需重取」。

## 哪些是数据固有、做不了的

| 项 | 结论 |
|---|---|
| 盘中价格漂移 | 数据源本身如此，只能标注 + 禁止当定值用 |
| 中枢右端重绘（BACKSET） | 与通达信口径绑死，改掉就不是同一套缠论了 |
| 涨停价依赖交易所规则 | 已按 10% / 20% 比例由公式自己给，不做硬编码判定 |
