# mew 问股 v1.10.22

## 数据源：三处缺口补齐

上一版把「优先级」写进了注释，但只写了一部分。这次查了自己的代码，找出三处真实的缺口。

### 缺口 1：快照只有两级，且备选是最差的源

```dart
Future<Quote> quote(String symbol) async {
  try {
    return await _quoteTencent(code);
  } on StockDataError {
    return await _quoteEastmoney(code);   // ← 没有新浪，直接降到东财
  }
}
```

K 线是**三级**（腾讯→新浪→东财），快照只有**两级**，而且第二级正是风险表里排最末、且是**延迟行情**的东财。**等于把最不稳的源当成唯一备选。**

现在补上新浪：

```
腾讯（实时，GBK） → 新浪（实时，GBK） → 东财（延迟行情）
```

新浪快照字段我实测核对过：

| 位 | 含义 | 实测值 |
|---|---|---|
| 0 | 名称 | 阳光电源 |
| 1-5 | 今开/昨收/现价/最高/最低 | 70.000 / 70.410 / 70.230 / 70.970 / 68.680 |
| 8 | 成交量（**股**） | 35965320（÷100 转手，与腾讯统一） |
| 9 | 成交额（元） | 2517296362.380 |
| 30 / 31 | 日期 / 时间 | 2026-11-23 / 15:35:45 |

### 缺口 2：没有统一的优先级文档

优先级散在三处（`market_source.dart` 注释、`data-sources.md` 的接口表、`stock_source.dart` 的代码顺序），三者没对齐，读不出全局。

新建 **`docs/data-source-priority.md`**，声明为唯一权威：

- **11 类用途** × 首选/备选/末位 × 风险等级 × 实测结论
- **明确列出 4 项不可用**及原因（北向资金/涨跌家数/连板细分/财经新闻）
- 限流规则表（腾讯约 600 次限流、新浪需 Referer、东财串行 350ms）
- 降级留痕要求
- 待办（交易所官方源未接入等）

`stock_source.dart` 与 `market_source.dart` 的文件头都指向它。

### 缺口 3：快照降级不留痕

`kline` 降级会写 `fallbackReason`，`quote` 不会。**东财是延迟行情，字段一样但时效不同**，不标出来模型会把延迟价当实时价用。

现在：

```dart
class Quote {
  final String? fallbackReason;
  bool get delayed => fallbackReason != null;
  Quote withFallback(String reason) => ...;
}
```

`stock_quote` 输出：

```json
{
  "price": 70.23,
  "as_of": "2026-11-23 15:35:45",
  "degraded_reason": "腾讯快照格式异常",
  "note": "这份快照来自备源（东财延迟行情），不是实时价"
}
```

### 顺带

快照也加了**同源重试一次**（250ms 退避），与 K 线行为一致。确定性错误不重试。
