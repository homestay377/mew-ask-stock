# mew 问股 v1.10.15

## 子智能体：从「能跑」到「跑得稳、花得明白」

六件事一起做，前四条在引擎层，后两条在界面层。

### 1. 并发闸：同时最多 3 个

原来：

```dart
await Future.wait([for (final t in ready) _runOne(...)]);
```

6 条任务会**同时**打同一个供应商，很容易 429，然后整批失败。

现在是 worker 池排队：

```dart
const maxConcurrentTasks = 3;
var cursor = 0;
Future<void> worker() async {
  while (true) {
    if (isCancelled()) return;
    final i = cursor++;
    if (i >= ready.length) return;
    await _runOne(ready[i], ...);
  }
}
await Future.wait([for (var i = 0; i < maxConcurrentTasks && i < ready.length; i++) worker()]);
```

### 2. 失败自动重试一次

`TeamTask` 增加 `retries`。子任务失败且没被取消时，换一份**更短的提示**重派一次：

```
（上一次没跑通。这次只要结论：直接给判断和关键数字，不要再试点、不要长篇复述过程。）
```

仍失败才标 `failed`。

### 3. 单工具超时按工具配

原来一刀切 3 分钟，`scan_stocks`、`stock_levels`、`http_request` 经常超时被判失败，而分派本身有 15 分钟。

| 工具 | 超时 |
|---|---|
| `scan_stocks` / `stock_levels` / `http_request` | 8 分钟 |
| `analyze_chan` / `stock_kline` / `get_fundamental` | 5 分钟 |
| 其余 | 3 分钟 |

### 4. token 总预算

`TeamBoard.usedTokens` 累加各任务的输入+输出；默认预算 20 万 token，`dispatch_subagents` 新增 `token_budget` 参数可覆盖。

超预算时剩余 `pending` 标 `skipped`，原因写「超出 token 预算（已用 X / Y）」，不再把剩下的任务也烧掉。

### 5. 成本可见：主对话也算进去

面板合计行原来是纯团队口径，现在补上主模型自己花的：

```
本次合计 ↑157.9K ↓537 · 158.4K tokens · 主对话 +42.1K · 23m10s
```

主对话用量由 `chat_page._conversationTokens()` 汇总整段对话的消息 usage。

### 6. 步骤结构化：不再是整段 JSON

任务详情弹窗里，步骤按类型分色：

- **推理**：斜体淡色 + 心理学图标
- **正文**：普通正文
- **工具**：✓/✗ 图标 + 工具名 + 耗时 + 输出摘要（小字）

## 顺带核实的一条

「主对话成本不可见」其实**已经可用**——`showTokenUsage` 默认 `true`，`ChatController:536` 也把 `usage` 写进了消息。所以这条改成「把两处合并展示」，不是新增开关。
