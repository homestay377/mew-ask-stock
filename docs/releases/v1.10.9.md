# mew 问股 v1.10.9

## 团队界面：从「假界面」到真的能看见

上一版把任务板做进了「智能体团队」面板，但那个面板有个致命问题：**只在打开那一刻读一次数据，之后没有任何刷新**。所以分派跑起来的时候，看起来就是一张死界面。

这一版把实时视图铺到三个地方。

### 1. 聊天流里的分派卡片，本身就是任务板

不用点开任何面板，任务卡就在对话里：

```
子智能体分派                    481.2s
阳光电源多维度团队分析
┌────────────────────────────────────┐
│ ◐ 直接执行联网调研，不得拒…   [运行中] │
│   t1 · 研究员                        │
└────────────────────────────────────┘
┌────────────────────────────────────┐
│ ◐ 调研最新财务表现与增长质量  [运行中] │
│   t2 · 研究员                        │
└────────────────────────────────────┘
┌────────────────────────────────────┐
│ ○ 只审查不修改，负责综合评审  [等待前置]│
│   t4 · 审查员                        │
│   依赖：t1、t2、t3                    │
└────────────────────────────────────┘
3 个运行中 · 1 个等待前置   ↑157.9K ↓537
```

数据来源是运行期一路推上来的 `meta.board`，不是等分派结束才解析 JSON。

### 2. 每个子智能体都能单独停

- 每条任务一个独立的取消令牌，运行中的任务行右侧有终止按钮；
- 停一个，同批其他任务继续跑；
- 主控整体停止仍然一次停全部（全局取消会联动到每个子任务）。

### 3. 输入框上方的团队运行中横幅

会话里有还没返回的分派时，输入框上方出现：

```
[团队] 团队运行中 · 发送的消息会直接交给团队      查看智能体团队 ›
```

点右侧直接打开任务板；这时候输入的话照旧发给主智能体，它能看着任务板决定是追加还是回答。

### 4. 面板也跟着活了

面板改为 400ms 轮询刷新，成员卡三态（运行中带当前任务摘要 / 等待前置 / 待命），主控显示「协调 N 个子智能体」。

### 顺手修的

- `_taskCard` / `_showOutput` / `_stateOf` 里参数名 `t` 遮蔽了 i18n 的 `t()` 函数，循环内调用翻译会直接编译失败；
- 卡片头部补上 `add_team_tasks` / `http_request` / `workspace_*` 的标题与图标。

## 验证

- CI `Analyze & test` 通过；

## 还没做

- `add_team_tasks` 仍发生在 dispatch 返回之后，不与仍在跑的子任务真并行；
- 子智能体逐 token 实时输出（现在只有状态，没有它的思考流）；
- 子智能体 token 归集进主对话用量统计。
