# mew 问股 v1.10.19

## 1. K 线胶囊：冷启动也显示股票名称

上一版改成「名称优先」了，但截图里还是代码。根因是**名字根本拿不到**：

```dart
// setSymbol 只在切股时赋值；冷启动走的是 restore()
if (nm != null && nm.isNotEmpty) _name = nm;
```

旧版本存的文件里没有 `name` 字段，`restore()` 读不到就一直是空——之后也不会去补，所以永远退化成显示代码。

现在 `restore()` 里补两步：

1. 先从本地自选查（`WatchlistStore.nameOf`），命中直接用；
2. 查不到就异步 `quote` 一次，拿到名字后 `notifyListeners()` 并回写文件。

下次启动就有名字了。

## 2. 扩展面板记住上次选中的页签

「+」里那四个页签（快捷短语 / 模式 / 世界书 / 记忆）每次点开都跳回「模式」，因为：

```dart
late ExtensionTab _tab = widget.initialTab ?? _firstUseful();
```

`initialTab` 从来没被传过，`_firstUseful()` 又按「第一个有内容的页签」算，所以每次都是同一个。

改法：

- `AppSettings` 新增 `lastExtensionTab`（持久化到 `settings.json`）；
- 切换页签时写入 `store.update((s) => s.copyWith(lastExtensionTab: tab.name))`；
- 打开时优先读它，读不到才退回 `_firstUseful()`。

**存的是枚举名字不是序号**——将来 `ExtensionTab` 增加成员或调整顺序，旧配置也不会错位到别的页签。

## 3. 三个参考项目：我看到了什么

### `1nchaos/adata`（Python SDK，多源融合）

数据面覆盖得比我们全，而且都是**公开接口**：

| 我们有 | 他们额外有 |
|---|---|
| 个股 K 线、报价、基本面 | **北向资金**（沪深港通实时/分时/历史） |
| 指数、板块涨幅榜 | **融资融券余额** |
| — | **龙虎榜**（列表 + 单股详情） |
| — | **热门榜单**（东财人气 100、同花顺热度 100、热门概念 20） |
| — | **限售解禁**列表 |
| — | 个股/概念**资金流向**（分时 + 历史） |
| — | 五档盘口、分笔成交 |
| — | 可转债、ETF 行情 |

关键设计：**多数据源融合切换**，单源失败自动换源；并且内置代理设置（"基于公开接口，可能存在限制"）。

这直接印证了我实测到的东财限流问题——他们把「多源」当第一原则。

### `ZhuLinsen/daily_stock_analysis`（AI 分析系统）

架构层面值得抄的是**数据源分层**：免费源零配置跑（AkShare / Baostock / YFinance），token 型源（Tushare / Longbridge）作为可选增强，并**明确写清每个市场的能力边界**（`docs/market-support.md`）。

策略层给了 15 种内置策略（均线、缠论、波浪、趋势、热点、事件、成长、预期…），我们只有缠论一套——但这是产品定位差异，不是缺陷。

值得警惕的是它自己写的：「免费源受上游限流、接口变动和网络波动影响，稳定性不保证」。

### `simonlin1212/a-stock-data`（87 端点 / 34 数据源）

这个最有价值，因为它**按封 IP 风险给数据源排了序**：

| 优先级 | 数据源 | 封 IP 风险 |
|---|---|---|
| 1（首选） | 腾讯财经 | **不封 IP**（K 线约 600 次后限流，已三入口轮换） |
| 2 | 交易所/官方机构 | 极低 |
| 3 | 新浪/巨潮/同花顺/百度/财联社 | 低 |
| 末位 | **东财 datacenter / push2** | **中 —— 有风控会封 IP** |

原则写得很直白：**「能用腾讯/交易所官方，就别用东财」**。

### 这三份材料合起来，指向我们一个真实缺陷

我们现在的 `market_overview`（指数、板块涨幅榜）**全部走东财 push2**，而按上面这份风险表，东财是「会封 IP」那一档。我今天实测时就撞到过限流——不是偶然，是设计问题。

**下一步该做的（按收益排序）：**

1. **市场数据换源**：指数改走腾讯（不封 IP），板块才留东财，并加限流；
2. **补北向资金**：adata 和 a-stock-data 都做得到，我们完全没有这一项，而它是判断主力方向的重要指标；
3. **补融资融券 / 龙虎榜 / 热门榜**：这三项长期缺失，现在知道从哪拿了；
4. 数据源统一加「多源降级 + 限流」，不再单点依赖东财。
