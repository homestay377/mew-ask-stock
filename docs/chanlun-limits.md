# 缠论引擎的口径与已知限制

> 这份文档记录**验证过的事实**，不是推测。每条都附了复现方法。

## 1. 结构不随窗口无限增长（400 根起收敛）

`BARSLAST` / `SUMBARS` / `BACKSET` 依赖左侧历史，窗口太短会在左沿凭空造结构。

实测 300274 日线：

| 根数 | 笔 | 中枢 |
|---|---|---|
| 200 | 14 | 1 |
| 270 | 18 | 2 |
| 300 | 20 | 3 |
| 400 | 26 | 4 |
| 640 | 38 | 4 |

**结论：取数一律 640 根**（腾讯上限）。`viewStart` 只裁显示范围，不影响计算。

## 2. 公式包含未来函数，会重绘

`assets/stock/chan_formula.txt`（255 行）里：

| 函数 | 次数 | 性质 |
|---|---|---|
| `REF` | 336 | 正常（向过去取值） |
| `DRAWLINE` | 10 | 画连线，会覆盖已画部分 |
| `REFX` | 8 | **向未来取值** |
| `BARSNEXT` | 4 | **向未来查找** |
| `BACKSET` | 2 | **回溯填值，改写历史 K 线** |

关键语句：

```
X_195:=BACKSET(BARSLAST(X_192)=0, SUMBARS(X_71>0,2)-1);
```

`BACKSET` 会把结果**回填到过去 N 根**。这意味着**指标是重绘的**：后面的 K 线出现后，会改写前面 K 线的值。

**这不影响绘图正确性**（通达信本来就是这么画的），但意味着：

> **图表上画出来的结构，不等于当时就能实时确认的结构。**

### 实测：中枢边界会变

追踪同一中枢（起点 27）在不同截断长度下的边界：

| 截断 | 中枢 | ZG | ZD |
|---|---|---|---|
| 300 | 不存在 | — | — |
| 400 | 不存在 | — | — |
| 500 | [27-386] | 71.740 | 62.240 |
| 640 | [27-386] | 71.740 | 62.240 |

- **ZG / ZD 稳定**（71.740 / 62.240 不变）
- **存在性依赖窗口**：300 / 400 根时这个中枢根本算不出来

另一个中枢的右边界会变：

| 截断 | 中枢 |
|---|---|
| 500 | [387-**490**] |
| 640 | [387-**485**] |

**结论**：`ZG`/`ZD` 可信，`e`（右边界）会重绘，中枢的存在性依赖足够历史。

## 3. 背驰级别曾使用未来数据（已修）

**原实现**：

```dart
final lv = boxes.length >= 2 ? '趋势' : '笔';
```

`boxes` 是**全历史**算出的中枢列表。信号发生在 idx=123 时，用它来判断级别，
会把之后才形成的 2 个中枢也数进去。

**实测证据**（截断回放对比）：

```
信号 idx=123
  按当天数据（128 根） → 中枢 1 个 → 笔背驰
  按全量（640 根）      → 中枢 4 个 → 趋势背驰   ← 未来数据
```

**修复**：只数信号那根之前已经结束的中枢。

```dart
final boxesSoFar = boxes.where((b) => b.e <= cur.to).length;
final lv = boxesSoFar >= 2 ? '趋势' : '笔';
```

修复后，截断回放与全量计算的级别**完全一致**。

早期两个信号（idx=123、215）从「趋势」修正为「笔」。

> ⚠ 注意：`e` 本身是重绘的（见第 2 节）。用 `e <= idx` 判断"该中枢在信号前已结束"
> 是一个合理近似，但不是逐根回放的精确结果。要得到严格结果需要 O(n²) 回放。

## 4. 中枢引用曾选错（已修）

**原实现**：

```dart
for (final bx in boxes) {
  if (bx.e <= sg.idx) lastBoxAt = bx;   // 取列表里最后一个满足的
}
```

`boxes` 按**起点**排序。一个起点更晚但结束更早的中枢，会覆盖起点早、结束晚的。

实测 idx=452：

| 中枢 | e | 结果 |
|---|---|---|
| 红[28-387] | 387 | 先被选中 |
| 绿[247-323] | 323 | **覆盖掉上面**，ZG=66.42 |

**修复**：判据改成 `s <= idx`（中枢已经开始形成），取 `s` 最大者。

因为中枢的 `e` 是事后才确定的，信号完全可能落在它形成过程中
（idx=452 时 `[387-485]` 正在形成，用 `e <= idx` 会把它排除）。

另外加了距离约束：信号价离中枢边界超过 **1.5 倍中枢高度**时不再判定——
那已经是另一个结构，不是「回抽不破 ZG」。

修复后 300274 的买卖点从 5 个降到 3 个，但每个都有实战意义：

```
一卖 @208.56  引用 ZG=183.86  ✓（原来引用 ZG=66.42）
二卖 @183.86  同上
一买 @139.78  引用 ZD=158.95  ✓
```

## 5. 公式里有 4 个函数未实现，但不影响结论

`runFormula` 会记录未实现的函数名（`FormulaResult.unknownFunctions`）。

真实缠论公式跑出来是：

```
CODELIKE、DTPRICE、NAMELIKE、ZTPRICE
```

**它们只出现在第 1–4 行**，用于计算「今日涨停价 / 今日跌停价」：

```
今日涨停价:=IF(NAMELIKE('ST') OR ... ,ZTPRICE(REF(C,1),0.05), ...);
今涨停价:今日涨停价,NODRAW;
```

第 3、4 行是 `NODRAW`（只输出不画），**后续公式完全没有引用这两个变量**。

**结论：这 4 个函数不影响笔、中枢、背驰、买卖点。**

> 这条值得记下来，否则每次看到「4 个函数未实现」都会重新调查一遍。

## 6. 买卖点的确认时点

| 类型 | 确认方式 | 是否实时可判 |
|---|---|---|
| 一买 / 一卖 | 背驰信号 + 价格在中枢外 + 距离约束 | **是**（信号当根即可判） |
| 三买 / 三卖 | 背驰信号 + 价格在中枢外 | **是**，但规则做了简化 |
| 二买 / 二卖 | 一买之后遍历 `bi` 找下一个不破前低的下跌段 | **否**（要等回调发生） |

两点必须知道：

**a) 二买/二卖是事后确认的。** 图表上标在回调低点，是那个时点才成立的。
如果 AI 在 idx=452 说"接下来会有二买"，那是预测，不是信号。

**b) 三买/三卖的规则是简化的。** 严格定义要求"突破中枢后回抽不破边界"，
当前实现只检查「背驰信号的价格位置 + 距离约束」，**没有验证回抽过程**。

这是规则简化，不是 bug。但输出措辞上不能说得比实际更确定。

## 7. 验证方法

```bash
# 结构回归（笔 / 中枢 / 公式序列逐值对比）
dart run tool/verify_golden.dart

# 截断回放一致性（需要自己写，模板见下）
```

截断回放的基本思路：

```dart
final full = Chanlun.analyze(allBars, formula);
for (final T in [300, 400, 500, 600]) {
  final partial = Chanlun.analyze(allBars.sublist(0, T), formula);
  // 对比 idx < T 的信号：级别、类型、价格应一致
}
```

**判据**：同一个 `idx` 的信号，在「截断到 T」和「全量」两种计算下，
`label` / `type` / `strength` 必须一致。不一致就是未来数据泄漏。

## 8. 已知但未修

1. **`e` 重绘**：中枢右边界会随后续 K 线调整，`boxesSoFar` 用 `e <= idx` 是近似
2. **三买/三卖未验证回抽**：规则简化，输出时要留余地
3. **O(L²)**：640 根约 30ms，2000 根以上需要改前缀和递推
4. **`mergeBoxes` 的 60% 阈值**：只做过单一样本验证，不同走势风格的适用性未测
